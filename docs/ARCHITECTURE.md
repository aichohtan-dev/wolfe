# Wolfe Architecture

## Phase 1 — Storefront
React/Vite/Tailwind UI with product discovery, collection filtering, product detail, wishlist/cart foundations.

## Phase 2 — Commerce API
Spring Boot modules:
- products
- categories
- collections
- inventory
- cart
- orders
- payments
- customers
- reviews
- consultations

## Phase 3 — Operations
Admin catalog, inventory, orders, refunds, CMS, analytics and audit logs.

## Design principle
Use the supplied Mantara site only as a visual/product-category reference. Wolfe uses original naming, copy, components and implementation.
